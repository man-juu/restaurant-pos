# Demo kitchen (fictional)

A fictional Korean cloud kitchen shaped like the owner's reference case (docs/09 entry 0.26):
A) frozen packs from the central kitchen, counted in pieces with expiry dates; B) local-market
items (rice, eggs, onion, oil, milk) in kg, l and pcs; C) packaging that does not spoil.
Names and prices are invented.

Try it on a fresh business:

1. Outlets: create an outlet named **Demo kitchen**.
2. Catalog → Items → Import → `items.csv` (categories are created automatically).
3. Catalog → Items → Import → Recipes → `recipes.csv`, then open each dish and activate its draft recipe.
4. Stock → Import opening stock → `opening-stock.csv`.

Each import can be undone from "Past imports".
